# Token Architecture

## Token Architecture

The new Hera Token is built on an omnichain-ready architecture designed to allow HERA to expand across multiple blockchain ecosystems while preserving a unified token economy.

HERA initially launches on Ethereum using the LayerZero OFT V2 standard.

### Initial Deployment

**Network:** Ethereum\
**Token:** Hera Token (HERA)\
**Contract:** 0x170FC64A94975C8556F6c0e699d3cc565D664473\
**Standard:** ERC-20 / LayerZero OFT V2\
**Decimals:** 18

Ethereum represents the first official distribution network of the new HERA token.

### Multichain Expansion

HERA is not intended to remain isolated to a single network.

Its token architecture is designed to support future deployments across major blockchain ecosystems while maintaining consistent supply accounting and token identity between supported networks.

Solana is planned as the first major expansion of the new HERA token, with additional networks potentially following as the Hera ecosystem grows.

Network availability, bridge routes and official contract addresses will always be announced and listed in this documentation before they are considered active.

### Unified Supply

Future network deployments are intended to operate as extensions of the same HERA economy rather than independent versions of the token.

Hera will maintain strict supply accounting across supported deployments to prevent duplicated economic supply.
