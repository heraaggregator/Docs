# Token Overview

## Hera Token

HERA is the native utility token of the Hera ecosystem, designed to support an expanding multichain protocol economy around routing, execution and liquidity infrastructure.

Following the 2026 token migration, Hera introduced a new generation of the HERA token with an omnichain-ready architecture and unified supply model.

Ethereum is the first official deployment and distribution network for the new Hera Token.

HERA is designed for future expansion across major blockchain ecosystems without creating independent economic versions of the token. Additional deployments will be introduced progressively as Hera's ecosystem expands, with Solana planned as the first major network expansion.

Only contracts listed in the official Hera documentation should be considered valid HERA contracts.

### Token Utility

HERA is designed to serve as the economic coordination layer of the Hera ecosystem. Utility will continue evolving alongside the protocol, including governance, protocol incentives, liquidity programs and other mechanisms connected to Hera's products and revenue model.

Some utility models remain under development and may change as Hera moves toward its stable release.

> **Token Migration**
>
> HERA completed a 1:1 token migration on October 22, 2026. Previous Ethereum and Metis HERA contracts are now legacy assets and should not be used as active HERA tokens.
>
> Migration details and legacy contracts can be found in **Legacy Token & Migration**.
